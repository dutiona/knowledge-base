Michaël, the plan needs revision before implementation. Confidence: high in the deadline and decompression findings; the proposed transport tests do not exercise those failure modes.

- **[BLOCKER] The deadline does not bound response headers or every body read.** The plan checks time before `client.send()` and after decoded chunks ([plan:64](docs/plans/2026-11-17-588-ingest-caps.md:64), [plan:72](docs/plans/2026-11-17-588-ingest-caps.md:72)). But httpcore can perform repeated socket reads while waiting for complete headers, each with the same timeout ([http11.py:170](.venv/lib/python3.12/site-packages/httpcore/_sync/http11.py:170), [http11.py:209](.venv/lib/python3.12/site-packages/httpcore/_sync/http11.py:209)). A server can drip an incomplete header indefinitely without returning control to the helper. The pinned transport can also retry multiple addresses with the same timeout ([utils.py:176](src/knowledge_base/utils.py:176)). D3’s claimed deadline-plus-one-read bound is therefore false. Use a deadline-aware transport or another cancellation mechanism covering header reads and address attempts, while preserving the floor; test a slow header drip and multiple failed addresses. Explicitly resolve the DNS exception against the acceptance criterion.

- **[HIGH] Decoding before counting permits a compressed response to exhaust memory.** `iter_bytes()` decompresses a raw chunk before yielding it ([httpx _models.py:894](.venv/lib/python3.12/site-packages/httpx/_models.py:894)); gzip and deflate call `decompress()` without an output limit ([httpx _decoders.py:67](.venv/lib/python3.12/site-packages/httpx/_decoders.py:67), [httpx _decoders.py:95](.venv/lib/python3.12/site-packages/httpx/_decoders.py:95)). The oversized allocation happens before the planned check ([plan:72](docs/plans/2026-11-17-588-ingest-caps.md:72)). Decoder buffering can also consume raw input without yielding a chunk for the deadline check. Use bounded incremental decompression, or request identity encoding and reject unsupported encoded responses; test highly compressible input and a compressed stream that makes no decoded progress.

- **[HIGH] A clipped timeout can produce the wrong error, and completion is not always checked against the deadline.** The plan retains the generic error for every `httpx.HTTPError` ([plan:88](docs/plans/2026-11-17-588-ingest-caps.md:88)). If the remaining deadline clips a read timeout, expiration raises an HTTP timeout before a chunk is yielded, so the caller receives the generic error instead of the promised deadline and variable. A delayed empty response or EOF after the last chunk can likewise finish without a final check. Check elapsed time after send and stream completion and when handling timeouts; classify deadline expiry explicitly. Add tests for blocked reads, empty bodies and delayed EOF.

- **[MEDIUM] The image test has mutually inconsistent expected results.** The plan says each failing image is skipped while a second valid image is described, yet expects `_extract_html_images` to return `0` ([plan:139](docs/plans/2026-11-17-588-ingest-caps.md:139)). That function returns the number of figure chunks added ([web.py:353](src/knowledge_base/web.py:353)). Assert one added figure and verify it belongs to the valid image, with a separate zero-result case if needed.

- **[LOW] The default-limit test does not establish the defaults.** A small page and two redirects ([plan:134](docs/plans/2026-11-17-588-ingest-caps.md:134)) would also pass with many incorrect defaults. The settings tests should assert the exact three default values, and the transport tests should establish the redirect boundary when unset.

**No other blocker, high, medium or low findings.** The reviewed httpx source supports the plan’s redirect construction, cookie handling, response encoding for this client, decoded-byte iteration and copied timeout-extension approach. The fake transport can observe the pinned request’s extensions, but its handler replaces the real HTTP transport ([conftest.py:149](tests/conftest.py:149)), so those tests alone cannot establish real socket timeout behavior.
